The math

This is the real-data version of the Z's you've been squaring and stacking above.

Expected count for row i, column j Eij=Ri×CjN R = row total, C = column total, N = grand total
Pearson residual rij=Oij−EijEij This is the piece that behaves like one of the Z's above, once N is reasonably large.
χ² statistic χ2=∑i,j(Oij−Eij)2Eijdf=(r−1)(c−1) Square and sum the residuals above, cell by cell — the same squaring-and-summing this page does with Z's. One catch: the lab table has 6 residuals but df = 2, because once the row and column totals are fixed only (r−1)(c−1) = 2 cells are free to vary. So compare the lab's χ² with the df = 2 curve, not df = 6.
Z₁, Z₂, … are independent standard normal values. Repeat χ² = Z₁² + Z₂² + … + Z_df² many, many times, and the distribution of those totals converges to the χ² distribution with df degrees of freedom.
