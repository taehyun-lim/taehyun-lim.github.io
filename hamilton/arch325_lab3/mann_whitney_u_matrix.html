What U is actually counting

Mann-Whitney U, Cell by Cell

Every Bethel value (rows) is compared against every Glenns/Dragon value (columns). A green cell means the row value is smaller; U is just how many green cells there are (ties count as half).

Bethel (rows) vs. Glenns/Dragon (columns)

Green = Bethel value is smaller · amber = tie (½) · blank = Bethel value is larger

Bethel < Glenns/Dragon (1) Tie (½) Bethel > Glenns/Dragon (0)

Cross-check: the rank-sum shortcut

You never actually have to build this grid — Excel gets the same number from ranks

U counts "wins," so it only ever depends on which group's values tend to rank higher — not on how far apart the raw numbers are. That is the same rank-only logic Kruskal-Wallis uses for three or more groups.
