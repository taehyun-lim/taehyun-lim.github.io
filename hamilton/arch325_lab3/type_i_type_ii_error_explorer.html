H₀: no real difference H₁: real difference of size δ

Drag the dark vertical line, or use the α presets above, to move the threshold.

Type I error (α): reject H₀ when it's actually true (the shaded blue tail). Type II error (β): fail to reject H₀ when H₁ is actually true (the shaded copper tail). Power (1 − β) is how often you'd correctly detect a real effect of size δ with this sample size. This is a simplified one-test picture, not the exact machinery behind χ² or Kruskal-Wallis, but the trade-off it shows (bigger n and bigger real effects both shrink β) is the same one driving every test on this site.
